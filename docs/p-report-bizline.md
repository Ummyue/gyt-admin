## 1. 业务定位

**业务线台账表**是数据中心的 6 张业务报表之一——按"业务线"维度汇总业务线全链路信息（货转/库存/支付/回款/结算），是业务线全生命周期数据查询入口。

## 5. 数据规则

- **上游货转** = 该业务线所有上游货转单数量合计
- **下游货转** = 该业务线所有下游货转单数量合计
- **库存** = 上游货转 - 下游货转（数量维度）
- **向上游支付** = 该业务线所有付款单金额合计
- **下游合同回款** = 该业务线所有下游销售合同应回款金额合计
- **下游业务回款** = 该业务线所有实际回款单金额合计
- **上游结算数量** / **上游结算金额** = 该业务线已上游结算单的数量/金额合计
- **下游结算数量** / **下游结算金额** = 该业务线已下游结算单的数量/金额合计
