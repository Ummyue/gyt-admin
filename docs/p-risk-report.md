## 1. 业务定位

**业务报表**（risk-report.html）是数据中心的**风险统计报表页**——业务人员查看全平台风险统计（预警分布 / 黑名单 / 违约次数 / 风险敞口等）。

> **页面归类说明**：`risk-report.html` 与 `report-risk.html`（已有 PRD）功能**重叠**，但字段和命名略不同：
> - `risk-report.html`（本页）：**早期版本**，v1.0 终版，命名简洁
> - `report-risk.html`（v1.7.99.x 终版）：**重构版本**，字段更完整

### 1.1 入口

| 入口 | URL | 说明 |
|------|------|------|
| 顶部菜单"数据中心" → **业务报表** | `./risk-report.html` | 主入口（旧版入口）|

---

## 2. 字段规则

### 2.1 顶部 4 KPI 卡片

| 卡片 | 指标 |
|------|------|
| 1 | 全平台风险敞口（敞口金额合计）|
| 2 | 预警总数（未处理）|
| 3 | 黑名单客户数 |
| 4 | 违约次数（30 天）|

### 2.2 风险统计表格

| 列 | 字段 |
|----|------|
| 客户名称 | display |
| 业务类型 | display |
| 敞口金额 | display |
| 风险评级 | tag（高/中/低）|
| 预警数量 | display |
| 最近预警时间 | display |
| 风险备注 | display |

---

## 3. 跨模块联动

| 联动 | 行为 |
|------|------|
| 预警中心（02.11） | 预警数据来自预警中心 |
| 客户管理（02.02） | 黑名单数据来自客户管理 |
| 合同管理（02.03） | 敞口金额来自合同 |

---

## 4. 异常处理

| 场景 | 处理 |
|------|------|
| 风险数据加载失败 | 各卡片显示"加载失败，点击重试" |
| 无风险数据 | KPI 显示 0 |
