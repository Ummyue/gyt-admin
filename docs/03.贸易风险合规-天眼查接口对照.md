## 五、注意事项

1. **接口 ID 已锁定**：表中粗体 ID（如 818、880、843、839、957、1124、453、449 等）经第三方集成商「快鲸智慧楼宇」长期使用验证，确认可被天眼查 API 网关接受。
2. **接口路径可能版本切换**：天眼查在 2024-2025 期间多次切换接口版本（如 `v2` → `baseinfoV2/2.0`），签约前请以 https://open.tianyancha.com/data 数据超市当前页为准。
3. **Token 限频**：基础版默认 QPS ≤ 20；超出需申请扩容。
4. **脱敏字段**：法定代表人身份证号、联系方式默认脱敏，需单独申请权限。
5. **价格随时调整**：表中价格来自数据超市展示页，签约时以商务报价为准（400-608-0000）。
