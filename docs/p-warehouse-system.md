## 1. 业务定位

**系统监控**（仓储子模块）是**仓储端的实时监控页**——业务人员查看仓房/库点的实时设备状态（温湿度、监控摄像头、门禁、消防等），快速发现异常。

| 维度 | 系统监控（本页）| 监控视频（warehouse-video）|
|------|------------------|------------------------------|
| 业务语义 | 设备状态总览 | 视频回放 / 实时画面 |
| 数据来源 | IoT 设备上报 | 监控摄像头 |
| 实时性 | 实时（5 分钟粒度）| 实时（视频流）|

### 1.2 入口

| 入口 | URL | 说明 |
|------|------|------|
| 顶部菜单"仓储管理" → **系统监控** | `./warehouse-system.html` | 主入口 |

## 2. 字段规则

### 2.1 顶部统计卡片（5 卡片）

| 指标 | 计算 |
|------|------|
| 库点总数 | COUNT(库点) |
| 在线设备数 | COUNT(设备 WHERE status=在线) |
| 异常设备数 | COUNT(设备 WHERE status=异常) |
| 离线设备数 | COUNT(设备 WHERE status=离线) |
| 今日巡检数 | COUNT(巡库 WHERE date=今日) |

### 2.2 设备状态表格

| 列 | 字段 |
|----|------|
| 设备编号 | display |
| 设备类型 | display（温湿度 / 监控 / 门禁 / 消防）|
| 库点 / 仓房 / 货位 | display |
| 设备状态 | tag（在线绿 / 异常黄 / 离线红 / 故障灰）|
| 最近上报时间 | display |
| 实时数据 | display（温度 / 湿度 / 视频预览）|
| 操作 | 查看详情 / 查看历史 |

### 2.3 筛选字段

| 字段 | 类型 |
|------|------|
| 库点 | select |
| 设备类型 | select |
| 设备状态 | select |
| 异常时间 | date-range |

---

## 3. 跨模块联动

| 联动 | 行为 |
|------|------|
| 监控视频 | 系统监控"查看详情" → 跳 warehouse-video |
| 巡库记录 | 系统监控发现异常 → 一键触发巡库 |
| 预警中心（02.11） | 设备异常触发预警（温湿度超阈值 / 设备离线）|
| 库存台账 | 温湿度异常可能影响库存货物状态 |

---

## 4. 异常处理

| 场景 | 处理 |
|------|------|
| 设备离线超过 1 小时 | 顶部红色 bar 提示"设备离线超过 1 小时" |
| 温湿度超阈值 | 红色字显示 + 自动触发预警 |
| 多个设备同时离线 | 提示"可能存在网络问题" |
