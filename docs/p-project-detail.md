## 7. 状态机

### 7.1 状态机流程图

```mermaid
stateDiagram-v2
    [*] --> pending_submit: 创建立项申请
    pending_submit --> auditing: 提交（v1.7.99.21+）
    pending_submit --> [*]: 申请人撤回

    auditing --> finished: 全部审批通过
    auditing --> rejected: 任一节点驳回
    auditing --> invalid: 申请人撤回

    finished --> frozen: 准入完成后归档
    rejected --> pending_submit: 重新编辑提交
    invalid --> [*]
    frozen --> [*]
```

### 7.2 状态机文字说明

```
pending_submit (待提交)
  ↓ 提交
auditing (审核中)
  ├─→ finished (已完结) ← 全部审批通过
  ├─→ rejected (驳回) ← 任一节点驳回
  └─→ invalid (作废) ← 申请人撤回
frozen (已冻结) ← 准入完成后归档
```
