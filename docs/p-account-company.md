## 1. 业务定位

**账户中心**是港通供应链的**账户管理模块**——企业管理本企业员工账号、角色权限、操作日志。

- **企业账户**（`account-company.html`）：企业管理员维护本企业员工账号、角色分配、权限控制
- **个人账户**（`account-personal.html`）：员工个人维护自己的账号信息、密码、消息订阅

**v1.7.99.152 当前状态**：原型置为**统一缺省页**——页面中明确描述"功能建设中（与线上保持一致）"，列出 5 项预期功能，原型无改动项。

## 3. 字段规则

### 3.1 预期字段（**线上系统**）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 账号 ID | 字符串 | 系统自动生成 |
| 员工姓名 | 字符串 | 真实姓名（已脱敏） |
| 登录手机号 | 字符串 | 138 XXXX XXXX（脱敏） |
| 所属部门 | 枚举 | 业务部/风控部/财务部/总经理办公室 |
| 角色 | 多选枚举 | 客户管理员/业务操作员/风控审核员/财务操作员/系统管理员 |
| 状态 | 枚举 | 启用/禁用 |
| 创建时间 | 日期时间 | yyyy-MM-dd HH:mm:ss |
| 最后登录时间 | 日期时间 | yyyy-MM-dd HH:mm:ss |
| 操作日志 | 列表 | 最近 N 条操作记录（最多 50 条） |

## 5. 异常处理

| 场景 | 处理 |
|------|------|
| 账号禁用 | 登录拦截 + 提示"该账号已禁用，请联系管理员" |
| 权限不足 | 按钮置灰 + hover 提示"无权限" |
| 操作日志超限 | 滚动加载 + 最多展示 50 条 |
