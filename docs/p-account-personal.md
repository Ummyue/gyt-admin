## 1. 业务定位

**个人账户**是港通供应链的**个人账号自助管理页**——员工个人维护自己的账号信息、密码、消息订阅、安全设置。

**与"企业账户"的区别**：
- **企业账户**（`account-company.html`）：企业管理员视角，维护本企业所有员工账号
- **个人账户**（`account-personal.html`）：员工个人视角，仅维护自己的账号

**v1.7.99.152 当前状态**：原型置为**统一缺省页**——页面中明确描述"功能建设中（与线上保持一致）"，列出 5 项预期功能，原型无改动项。

## 3. 字段规则

### 3.1 预期字段（**线上系统**）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 账号 ID | 字符串 | 系统自动生成 |
| 用户名 | 字符串 | 登录名（不可修改） |
| 真实姓名 | 字符串 | 实名认证姓名 |
| 手机号 | 字符串 | 138 XXXX XXXX（脱敏） |
| 邮箱 | 字符串 | xxx@example.com（脱敏） |
| 所属企业 | 字符串 | 自动关联 |
| 角色 | 字符串 | 展示当前用户角色 |
| 消息订阅 | 多选枚举 | 站内信/邮件/短信/钉钉 |
| 安全设置 | 子菜单 | 修改密码/绑定手机/绑定邮箱/二次验证 |
| 最近登录 | 列表 | 最近 10 次登录记录（含 IP/设备/时间） |

## 5. 异常处理

| 场景 | 处理 |
|------|------|
| 密码过期 | 登录拦截 + 强制修改密码 |
| 异地登录 | 二次验证 + 短信验证码 |
| 账号锁定 | 5 次密码错误 → 锁定 30 分钟 |
