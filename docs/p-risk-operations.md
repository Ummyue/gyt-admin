## 1. 业务定位

**风险运营管理**是预警中心的**风险运营视角页**——风控人员从"运营"角度管理所有预警（处理中预警 / 待审核预警 / 已处理预警 / 历史预警），含工单分配、SLA 监控等运营动作。

| 维度 | 风险运营管理（本页）| 预警列表（warning-list）|
|------|---------------------|-------------------------|
| 视角 | 风控运营（处理预警）| 业务人员（查看预警）|
| 操作 | 工单分配 / SLA 监控 | 查看 / 处理 |
| 范围 | 全平台预警 | 当前用户可见 |

### 1.1 入口

| 入口 | URL | 说明 |
|------|------|------|
| 顶部菜单"预警中心" → **风险运营管理** | `./risk-operations.html` | 主入口（风控人员）|

## 2. 字段规则

### 2.1 顶部 4 KPI 卡片

| 卡片 | 指标 |
|------|------|
| 1 | 待处理预警数 |
| 2 | 处理中预警数 |
| 3 | 今日新增预警数 |
| 4 | SLA 即将超时预警数（剩余 < 4 小时）|

### 2.2 工单分配表格

| 列 | 字段 |
|----|------|
| 预警编号 | display |
| 预警类型 | display |
| 严重程度 | tag（高/中/低）|
| 触发时间 | display |
| 处理人 | display（员工）|
| SLA 剩余 | display（红/黄/绿）|
| 状态 | tag（待处理/处理中/已处理/已超时）|
| 操作 | 分配 / 转交 / 处理 |

---

## 3. 按钮交互

### 3.1 主操作按钮

| 按钮 | 行为 |
|------|------|
| 批量分配 | 批量分配处理人 |
| 工单导出 | 导出当前工单列表 |

### 3.2 行操作按钮

| 按钮 | 行为 |
|------|------|
| 分配处理人 | 弹窗选处理人 |
| 转交 | 弹窗选转交对象 |
| 处理 | 跳 warning-detail 进入处理流程 |

---

## 4. 跨模块联动

| 联动 | 行为 |
|------|------|
| 预警中心（02.11） | 工单数据来自预警 |
| 用户管理（02.02） | 处理人来自用户账号 |
| 操作记录 | 工单分配 / 转交 / 处理 全部记入操作记录 |

---

## 5. 异常处理

| 场景 | 处理 |
|------|------|
| 当前用户非风控人员 | 顶部红色 bar 提示"无访问权限" |
| SLA 超时 | 红色字显示 + 自动通知处理人 |
| 处理人不存在 | 红字提示"该员工不存在" |
