## 1. 业务定位

**驾驶舱**是数据中心的**首页 / 仪表盘**——业务人员/管理人员一眼看到平台核心 KPI（业务规模 / 资金规模 / 风险敞口 / 业务线状态 / 预警计数等）。

| 维度 | 驾驶舱（本页）| 旧版 dashboard |
|------|------------------|-----------------|
| 数据范围 | 全平台汇总 | 单一项目维度 |
| 图表类型 | KPI 卡片 + 折线/饼图 | 简单数字展示 |
| 实时性 | 准实时（5 分钟）| T+1 日 |

### 1.1 入口

| 入口 | URL | 说明 |
|------|------|------|
| 顶部菜单"数据中心" → **驾驶舱** | `./cockpit.html` | 主入口 |

## 2. 字段规则

### 2.1 顶部 5 大 KPI 卡片

| 卡片 | 指标 | 计算公式 |
|------|------|----------|
| 1 | 业务规模（合同总数）| COUNT(合同 WHERE status ≠ 作废) |
| 2 | 资金规模（累计交易额）| SUM(合同金额) |
| 3 | 风险敞口（敞口金额合计）| SUM(敞口金额) |
| 4 | 业务线状态（执行中业务线数）| COUNT(业务线 WHERE status = 执行中) |
| 5 | 预警计数（未处理预警）| COUNT(预警 WHERE status = 未处理) |

### 2.2 中部 4 张图表

| 图表 | 类型 | 数据源 |
|------|------|--------|
| 1 | 折线图 | 近 30 日合同签订数量趋势 |
| 2 | 饼图 | 业务类型分布（存货/预付/账期/购销）|
| 3 | 柱状图 | 业务线执行状态分布 |
| 4 | 表格 | 最新 10 条预警（含预警类型/严重程度/触发时间）|

### 2.3 底部快捷入口

| 入口 | 跳转 |
|------|------|
| 项目台账表 | `report-project.html` |
| 业务线台账表 | `report-bizline.html` |
| 资金占压表 | `report-fund.html` |
| 库存明细表 | `report-inventory.html` |
| 应收应付表 | `report-ar-ap.html` |
| 风控统计报表 | `report-risk.html` |
| 合规验证报告 | `report-compliance.html` |

## 3. 按钮交互

| 按钮 | 位置 | 行为 |
|------|------|------|
| 导出报告 | 顶部 | 导出当前驾驶舱所有数据为 PDF |
| 刷新 | 顶部 | 重新拉取实时数据 |
| 切换时间范围 | 顶部 | 今日/本周/本月/本年/自定义 |

---

## 4. 异常处理

| 场景 | 处理 |
|------|------|
| 数据加载失败 | 各图表显示"加载失败，点击重试" |
| 时间范围查询无数据 | 图表显示"暂无数据" + KPI 显示 0 |
| 当前用户无驾驶舱权限 | 顶部红色 bar + 联系管理员 |
