## 1. 业务定位

**销售合同关联采购合同**是业务线关联的**方向 2 子页**——业务人员在已有销售合同时，**从销售方向找采购合同**，建立"上游供应商 + 下游客户"的完整业务线。

| 维度 | 销售关联采购（本页）| 采购关联销售（contract-purchase-relate-sales）|
|------|---------------------|----------------------------------------------|
| 起始合同 | 销售合同 | 采购合同 |
| 待关联合同 | 采购合同 | 销售合同 |
| 业务场景 | 已有下游销售方 → 找上游采购方 | 上游供应商发货 → 找下游销售方 |

### 1.1 入口

| 入口 | URL | 说明 |
|------|------|------|
| 销售订单/单批次合同详情"关联采购合同" | `./contract-sales-relate-purchase.html?salesNo={销售合同编号}` | 主入口 |

### 1.2 v1.7.99.59 关键改动

- 与 contract-purchase-relate-sales.html **对称**复制 v1.7.99.59 改造
- 顶部"选择采购订单"按钮（vs 方向 1 的"选择销售订单"）
- 已选合同信息卡：单条合同展示（合同编号/卖方/买方/品名/单价/数量）

> **页面命名对称性**：两个方向页面字段、按钮、异常处理**完全对称**，只有"销售/采购"称呼不同。

## 2. 业务流程全景

```mermaid
flowchart TB
    A[销售订单/单批次合同详情] --> B[点击"关联采购合同"按钮]
    B --> C[进入 contract-sales-relate-purchase.html]
    C --> D[区块 1: 销售合同信息 4 行 3 列 readonly]
    D --> E[顶部"选择采购订单"按钮]
    E --> F[弹窗选择采购合同]
    F --> G[选择后回显 已选合同信息卡]
    G --> H[点击保存]
    H --> I[二次确认弹窗]
    I -->|确定| J[业务线建立 跳业务线详情]
    I -->|取消| K[保留页面数据]
```

## 3. 字段规则

### 3.1 区块 1：销售订单/单批次合同信息（v1.7.99.59 4 行 3 列 readonly）

| 行 | 字段 |
|----|------|
| 1 | 卖方企业 / 买方企业 / 品名 |
| 2 | 计量单位 / 合同单价 / 合同数量 |
| 3 | 税率 / 签订日期 / 合同交货期限 |
| 4 | 运输方式 / 业务实际负责人 / 业务类型 |

### 3.2 区块 2：关联采购订单（贸易）合同信息

| 状态 | 显示 |
|------|------|
| 未选择时 | 蓝底提示框 + "请选择采购订单"按钮 |
| 已选择 | 已选合同信息卡（合同编号/卖方/买方/品名/单价/数量）|

### 3.3 校验规则

| 场景 | 校验 |
|------|------|
| 未选择采购合同 | 禁用提交按钮 + 顶部提示"请先选择采购合同" |
| 关联非"执行中"状态合同 | 红字提示"请选择执行中状态的合同" |
| 已关联业务线的合同重复关联 | 红字提示"该合同已关联其他业务线" |

## 4. 按钮交互

### 4.1 主操作按钮

| 按钮 | 位置 | 行为 |
|------|------|------|
| **选择采购订单** | 顶部 | 弹窗选择采购合同 |
| **保存** | 底部 | 二次确认 → 建立业务线 |
| **取消** | 底部 | 返回销售合同详情 |

### 4.2 辅助按钮

| 按钮 | 位置 | 行为 |
|------|------|------|
| 更换合同 | 已选合同卡右上 | 重新选采购合同 |
| 解除关联 | 已选合同卡右上（已关联时）| 二次确认 → 解除 |

### 4.3 二次确认弹窗

- **保存确认弹窗**：
  - 标题：保存确认
  - 内容：确认关联该采购合同？关联后业务线自动建立
  - 按钮：取消 / 确定

## 5. 异常处理

| 场景 | 处理 |
|------|------|
| URL 参数 `salesNo` 缺失 | 顶部红色 bar + 返回销售合同列表 |
| 销售合同已作废 | 顶部红色 bar 提示"该销售合同已作废，无法关联" |
| 关联非"执行中"状态合同 | 红字提示"请选择执行中状态的合同" |
| 已关联业务线的合同重复关联 | 红字提示"该合同已关联其他业务线" |
| 同一合同并发关联 | 二次校验被覆盖则提示"已被其他操作覆盖，请刷新" |

## 6. 跨模块流转

### 6.1 与业务线（02.06）

- 关联成功 → 业务线自动建立（上游供应商 + 下游客户完整业务线）
- 业务线状态=执行中（v1.7.99.169）

### 6.2 与采购/销售合同（02.03）

- 关联成功 → 采购合同"业务线"字段 = 业务线 ID
- 关联成功 → 销售合同"业务线"字段 = 业务线 ID

### 6.3 解除关联

- 解除关联 → 业务线**同步释放**（v1.7.99.169 关键决策）

### 6.4 与方向 1 的对称性

| 维度 | 方向 1（采购→销售）| 方向 2（销售→采购）|
|------|---------------------|---------------------|
| 起始合同 | 采购合同 | 销售合同 |
| 待关联合同 | 销售合同 | 采购合同 |
| 顶部按钮文字 | "选择销售订单" | "选择采购订单" |
| 区块 1 标题 | "采购订单/单批次合同信息" | "销售订单/单批次合同信息" |
| 区块 2 标题 | "关联销售订单(贸易)合同信息" | "关联采购订单(贸易)合同信息" |
| 校验规则 | 完全一致 | 完全一致 |
