## 1. 业务定位

**盘盈入库**是入库管理的**特殊类型新建页**——业务人员登记**实际库存大于账面库存**的货物入库（盘盈场景）。与"采购入库"区别：**不关联采购合同**，直接登记入库。

| 维度 | 盘盈入库（本页）| 采购入库（warehouse-inbound-new）|
|------|------------------|------------------------------------|
| 业务语义 | 实际库存 > 账面库存（盘盈）| 采购合同货物入库 |
| 关联合同 | ❌ 不关联 | ✅ 必填（采购合同）|
| 业务类型 | 盘盈入库 | 采购入库 |

### 1.1 入口

| 入口 | URL | 说明 |
|------|------|------|
| 入库记录列表 + 新增入库按钮 → 下拉选"盘盈入库" | `./warehouse-inbound-overflow-new.html` | 主入口（v1.7.99.100 列表页按钮下拉）|

### 1.2 v1.7.99.100 关键改动

- 从 v1.0 单一"新增入库"页拆为 **2 个类型**：
  - 采购入库（warehouse-inbound-new.html）
  - 盘盈入库（warehouse-inbound-overflow-new.html，本页）
- v1.7.99.100 列表页按钮下拉：点击"+ 新增入库" → 下拉选"采购入库 / 盘盈入库"
- 2 个页面共用同一表单结构，**仅合同字段差异**

## 3. 字段规则

### 3.1 区块 1：货物信息（10 字段）

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 品名 | input | 是 | 必填；引用 warehouse-category 单品名 |
| 入库数量（吨）| number input | 是 | 必填；min=0, step=0.01 |
| 入库单价（元/吨）| number input | 是 | 必填；min=0 |
| 入库日期 | date | 是 | 必填；不能晚于当前日期 |
| 产地 | input | 是 | 必填；汉字输入 |
| 业务类型 | select | 是 | 存货业务/预付业务/账期业务/购销业务 |
| 入库类型 | select | 是 | **盘盈入库**（默认锁定，不可改）|
| 关联合同 | display | - | **不关联**（v1.7.99.100 关键差异）|
| 运输方式 | select | 是 | 汽运/火运/船运 |
| 备注 | textarea | 否 | 选填 |

### 3.2 区块 2：仓房 & 货位

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 仓房 | select | 是 | 必填；引用 warehouse-warehouse 仓房 |
| 货位 | select | 是 | 必填；引用 warehouse-point 货位 |
| 数量 | number input | 是 | 必填；不能超过入库数量 |

**关键决策**：盘盈入库的"仓房 & 货位"必须从已有数据中选择（盘盈的货物必须放置在某仓位）。

### 3.3 区块 3：入库单据上传

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 入库单据 | upload | 是 | 凭证 jpg/jpeg/png/pdf；单文件 ≤ 100MB |
| 盘盈说明 | textarea | 是 | 必填；说明盘盈原因（如"实际盘点发现多出 X 吨"）|

**v1.7.99.100 关键决策**：盘盈入库**必须填写盘盈说明**——这是审计合规要求。

### 3.4 校验规则

| 场景 | 校验 |
|------|------|
| 仓房货位数量 > 入库数量 | 红字提示"仓房货位数量合计不能大于入库数量" |
| 入库日期 > 当前日期 | 红字提示"入库日期不能晚于当前日期" |
| 盘盈说明为空 | 红字提示"请填写盘盈说明（合规要求）" |
| 未选择仓房货位 | 红字提示"请选择仓房和货位" |

## 4. 按钮交互

### 4.1 主操作按钮

| 按钮 | 位置 | 行为 |
|------|------|------|
| **提交** | 底部 | 二次确认 → 写入入库记录（类型=盘盈入库）|
| **取消** | 底部 | 返回入库记录列表 |

### 4.2 辅助按钮

| 按钮 | 位置 | 行为 |
|------|------|------|
| 选择仓房 | 区块 2 | 弹仓房列表 |
| 选择货位 | 区块 2 | 弹货位列表（按仓房过滤）|
| 上传单据 | 区块 3 | 弹文件选择 |

### 4.3 二次确认弹窗

- **提交确认弹窗**：
  - 标题：提交确认
  - 内容：确认提交本次盘盈入库？提交后系统将更新库存台账的"实际库存"
  - 按钮：取消 / 确定
  - 成功后 toast："盘盈入库登记成功"

## 5. 异常处理

| 场景 | 处理 |
|------|------|
| URL 参数异常 | 顶部红色 bar + 返回入库记录列表 |
| 关联合同（不应有） | 红字提示"盘盈入库不需要关联合同" |
| 仓房货位不存在 | 红字提示"该仓房或货位不存在" |
| 未上传入库单据 | 禁用提交按钮 + 红字提示 |

## 6. 跨模块流转

### 6.1 与入库记录列表（warehouse-inbound）

- 提交成功 → 跳入库记录列表
- 列表刷新该入库记录（类型=盘盈入库）

### 6.2 与库存台账（warehouse-inventory）

- 盘盈入库完成 → 库存台账"实际库存" += 入库数量（v1.7.99.100 关键）
- 库存台账"账面库存" 不变（账面库存来自合同）
- **实际库存 - 账面库存 = 盘盈数量**（自动计算并展示）

### 6.3 与品类配置（warehouse-category）

- "品名"字段引用品类配置的单品名

### 6.4 与仓房管理（warehouse-warehouse）

- "仓房"字段引用仓房管理

### 6.5 与库点信息管理（warehouse-point）

- "货位"字段引用库点信息管理的货位
