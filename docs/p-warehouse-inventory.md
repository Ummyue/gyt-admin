## 1. 业务定位

**库存台账**是仓储管理的**库存总览页**——业务人员按仓房/品类/合同等多维度查看库存实际情况 + 账面情况 + 库存差异。

| 核心指标 | 计算公式 |
|----------|----------|
| **实际库存** | 入库数量 - 出库数量（含盘盈/盘亏调整）|
| **账面库存** | 来自合同应收货物数量 - 已收货物数量 |
| **库存差异** | 实际库存 - 账面库存（盘盈/盘亏）|

## 3. 跨模块联动

| 联动 | 行为 |
|------|------|
| 入库管理 | 入库登记 → 实际库存 += |
| 出库管理 | 出库登记 → 实际库存 -= |
| 盘盈/盘亏 | 盘盈入库 → 实际库存 += 盘盈数量 |
| 业务线 | 业务线"账面库存"按合同维度计算 |
