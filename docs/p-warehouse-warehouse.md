## 1. 业务定位

**仓房管理**是仓储管理的**二级数据维护页**——业务人员配置仓房（库点内的仓房）+ 货位（仓房内的具体货位）。

| 维度 | 仓房管理（本页）| 库点信息管理（warehouse-point）|
|------|------------------|---------------------------------|
| 数据范围 | 仓房 + 货位 | 库点（物理仓库地址）|
| 颗粒度 | 1 个仓房 = N 个货位 | 1 个库点 = N 个仓房 |

### 1.2 v1.7.99.91 关键改动

- 从 v1.0 仓房单列表重构为 **v1.7.99.91 仓房 + 货位二级结构**
- 每个仓房关联库点 + 货位数 + 容积 + 当前库存数

## 2. 字段规则

### 2.1 仓房字段

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 仓房编号 | auto | - | 系统生成 |
| 库点 | select | 是 | 引用 warehouse-point |
| 仓房名称 | input | 是 | 必填；同一库点下不可重复 |
| 仓房类型 | select | 是 | 平房仓 / 楼房仓 / 筒仓 / 其他 |
| 容积（吨）| number input | 是 | 必填；min=0 |
| 货位数 | int | - | 灰置（统计）|
| 当前库存（吨）| number | - | 灰置（统计）|
| 状态 | select | - | 正常 / 维修中 / 停用 |
| 操作 | button | - | 查看货位 / 编辑 / 删除 |

### 2.2 货位字段（v1.7.99.91 展开行）

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 货位编号 | auto | - | 系统生成 |
| 货位名称 | input | 是 | 必填；同一仓房下不可重复 |
| 容积（吨）| number input | 是 | 必填；不能大于仓房容积 |
| 当前库存（吨）| number | - | 灰置（统计）|
| 占用状态 | display | - | 空 / 部分占用 / 满 |
| 操作 | button | - | 编辑 / 删除 |

### 2.3 校验规则

| 场景 | 校验 |
|------|------|
| 删除有货位的仓房 | 红字提示"该仓房有 N 个货位，无法删除" |
| 货位容积 > 仓房容积 | 红字提示"货位容积合计不能大于仓房容积" |
| 删除已占用货位 | 红字提示"该货位正在使用，无法删除" |

## 3. 跨模块联动

| 联动 | 行为 |
|------|------|
| 库点信息管理 | 仓房 → 库点（1:N）|
| 入库管理 | 入库单据 → 货位 |
| 出库管理 | 出库单据 → 货位 |
| 库存台账 | 实际库存按仓房 + 货位聚合 |
| 巡库记录 | 巡库按仓房 + 货位登记 |
| 系统监控 | 仓房/货位关联 IoT 设备 |
