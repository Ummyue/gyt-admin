## 5. 数据规则

- **合同金额** = 该项目所有关联销售合同金额之和
- **累计回款** = 该项目所有回款单金额之和
- **项目状态** 由项目状态机决定：
  - 立项中：客户申请已提交但未审批通过
  - 执行中：项目已审批通过 + 合同已生效
  - 已完结：项目所有合同已结算 + 收发货完成
  - 已作废：项目手动作废

## 7. 跨模块流转

- **上游数据**：项目准入（02.03）→ 项目详情 → 项目台账表
- **下游消费**：项目台账表 → 资金占压表（按项目汇总资金占压）
- **状态联动**：项目状态变化 → 自动更新项目台账表 + 资金占压表
