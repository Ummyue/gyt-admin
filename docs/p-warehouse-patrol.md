## 1. 业务定位

**巡库记录**是仓储管理的**实地巡检页**——业务人员（仓储管理员）定期巡检仓房/库点/货位，记录巡检结果（含图片、视频、问题备注），并触发盘盈/盘亏调整。

| 维度 | 巡库记录（本页）| 库存台账（warehouse-inventory）|
|------|------------------|-------------------------------|
| 业务语义 | 实地巡检 + 问题记录 | 库存数据总览 |
| 触发场景 | 定期巡检 / 异常盘点 | 入库/出库/盘盈盘亏更新 |
| 输出 | 巡库记录 + 盘盈/盘亏建议 | 库存数据 |

### 1.2 v1.7.99.86 关键改动

- v1.7.99.86 仓储管理 9 子模块统一规范
- 巡库记录与库存台账**联动**：巡库发现的盘盈/盘亏可一键提交盘盈入库/盘亏出库

## 2. 字段规则

### 2.1 顶部按钮

| 按钮 | 行为 |
|------|------|
| **+ 新增巡库** | 弹窗填写巡库记录 |
| **数据导出** | 导出当前筛选 |

### 2.2 6 字段筛选区

| 字段 | 类型 |
|------|------|
| 仓房 | select |
| 货位 | select |
| 巡库人员 | select |
| 巡库日期 | date-range |
| 巡库结果 | select（全部 / 正常 / 异常 / 已处理）|
| 巡库类型 | select（定期巡检 / 异常盘点 / 抽查）|

### 2.3 巡库表格

| 列 | 字段 |
|----|------|
| 巡库编号 | display |
| 仓房 & 货位 | display |
| 巡库人员 | display |
| 巡库日期 | display |
| 巡库类型 | display |
| 巡库结果 | tag（正常绿 / 异常黄 / 已处理蓝）|

## 3. 跨模块联动

| 联动 | 行为 |
|------|------|
| 库存台账 | 巡库触发的盘盈/盘亏 → 实际库存更新 |
| 仓房管理 | 巡库记录关联仓房 |
| 库点信息管理 | 巡库记录关联库点 |
| 监控视频（warehouse-video） | 巡库时可调取监控视频 |
