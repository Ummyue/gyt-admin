## 1. 业务定位

**库存明细表**是数据中心的 6 张业务报表之一——按"仓库 + 商品"维度汇总库存全量信息（合同/品名/规格/材质/产地/数量/重量/预占/车船号），是库存全链路数据查询入口。

## 4. 按钮交互

| 按钮 | 行为 |
|------|------|
| 合同编号_我方（蓝字）| 跳采购合同详情 |
| 合同编号_客户方（蓝字）| 跳销售合同详情 |
| 所属上游货转（蓝字）| 跳货转详情 |

---

## 5. 数据规则

- **库存数量** = 入库数量 - 出库数量（按件计）
- **库存重量** = 入库重量 - 出库重量（按吨计）
- **预占库存** = 已锁定的库存数量（出库单已审批但未实际出库）
- **可售库存** = 库存数量 - 预占库存数量

---

## 6. 异常处理

| 场景 | 提示 |
|------|------|
| 库存为负数 | 红色异常标记 + "库存异常" |
| 预占库存 > 库存数量 | 黄色预警 |
| 数据加载失败 | "数据加载失败，请重试" |
