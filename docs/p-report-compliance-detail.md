## 5. 合作期间主体风险监控情况

### 5.1 取值逻辑

**取业务线关联的主体预警列表**，按规则类型分类汇总展示条数。

#### 5.1.1 主体范围

**排除**：警示企业名称 / 上游合同方 / 下游合同买方方 / 仓储方 / 运输企业
**包含**：其他主体（监管 / 关联方 / 工商公示 / 司法诉讼 / 经营风险）

#### 5.1.2 日期范围

```
起始日期 = min(采购合同起始, 销售合同起始)
结束日期 = max(采购合同结束, 销售合同结束)
```

#### 5.1.3 状态

**包含**：待处理 / 流程中
**排除**：已处理 / 已处理（人工）

### 5.2 展示样式

| 预警数量 | 展示形式 |
|---------|---------|
| = 0 | 12 个信息类型都是 0（文字 + 数量列）|
| ≠ 0 | 对应信息数量列显示 N，点击展开预警列表 |

### 5.3 表格结构（v1.7.99.206 锁定 12 信息类型）

| 分类 | 信息类型 |
|------|---------|
| 工商变更 | 工商信息变更 / 工商信息异常 / 税务评级异常 / 被执行人核查 / 被列入失信被执行人 / 被限制高消费 |
| 司法诉讼 | 股权冻结核查 / 破产重组核查 |
| 经营风险 | 严重违法核查 / 欠税公告核查 / 动产抵押核查 / 公示催告核查 |

**v1.7.99.206 决策**：12 个信息类型**固定枚举**——表格始终展示 12 行。

## 8. 上下游回款

### 8.1 回款情况

| 字段 | 展示规则 |
|------|---------|
| 回款情况 | **下游部分展示业务线回款情况**，与 Admin 端-回款管理-回款闭环监控-业务线数据-列表**保持一致**；**非"正常"时标红**；**上游展示"-"** |

### 8.2 回款总额

| 字段 | 展示规则 |
|------|---------|
| 回款总额 | **下游部分展示**，与业务线动态监控详情中下游回款（元）保持一致；**上游展示"-"** |

### 8.3 回款是否足额（v1.7.99.206 关键——足额/不足额 二元判断）

| 字段 | 展示规则 |
|------|---------|
| 回款是否足额 | **下游部分展示**；**不足额时标黄**；**上游展示"-"** |

#### 8.3.1 不足额（3 个条件同时满足）

- 下游回款金额 < 业务线结算总金额
- 且 下游回款金额 < 拆分到该合同下的贸易发票及运费金额之和
- 且 下游回款金额 > 0

#### 8.3.2 足额（任一条件满足）

- 下游回款金额 = 业务线累计回款金额
- 或 下游回款金额 = 拆分到该合同下的贸易发票及运费金额之和
- 或 下游回款金额 = 0（**完全未回款**——业务约定"未回款"是 0 状态，不归到不足额）

**v1.7.99.206 决策**：不足额 = 部分回款但**金额不足以覆盖**——标黄；足额 = 完全回款 **或** 完全未回款——**不标色**。

## 11. 校验结果状态说明（v1.7.99.206 新增）

合规验证报告检查结果有 **3 种状态**：

| 状态 | 含义 | 展示颜色 |
|------|------|---------|
| **通过** | 业务线该项检查通过，无异常 | 绿色 ✓ |
| **不通过** | 业务线该项检查未通过，存在异常 | 红色 ✗ |
| **未发生** | 业务线暂未发生该项检查所依赖的业务（如未开票、未结算）| 灰色 — |

**v1.7.99.206 决策**：
- "未发生" 状态**不影响整体合规评级**（只标记"通过"的项）
- "不通过" 状态**触发预警**——联动预警中心生成对应预警记录
- 整体合规评级 = (通过项数 / 应检查项数) ≥ 80% → 合规；< 80% → 不合规

## 13. 异常处理

### 13.1 业务线删除后报告处理

- 业务线被解除（v1.7.99.202 操作下拉）→ 对应合规验证报告**保留但不更新**（历史快照）
- 列表中已解除业务线的报告仍可见，点击"查看报告"打开后提示"该业务线已解除，报告为历史快照"

### 13.2 跨企业数据权限

- 当前账号所属企业 A，尝试查看企业 B 业务线报告 → 列表不展示，详情页 URL 直访提示"无权限"

### 13.3 业务线状态特殊展示

- 业务线状态 = 上游完结审批驳回 / 业务完结审批驳回 → 鼠标移入展示驳回原因
- 业务线状态 = 待审核 → 不展示审核按钮（仅业务线动态监控详情有）

## 14. 跨模块流转

### 14.1 报告生成触发链

```
定时任务（每 1 小时）
  ↓
检查业务线付款记录
  ↓
监测到业务线上关联有【已付款】的付款记录
  ↓
生成业务线合规报告（报告数据初始化）
  ↓
报告状态 = "已生成"
  ↓
列表页 report-compliance.html 显示该业务线报告
  ↓
用户点击"查看报告"
  ↓
跳转到详情页 report-compliance-detail.html
```

### 14.2 与业务线详情页联动

- 列表"业务线"列 / "业务线号"列 link → 跳业务线详情页 `business-line-detail.html`
- 业务线详情页"操作"下拉 → "查看合规验证报告"（v1.7.99.202/203）→ 跳详情页

### 14.3 与预警中心联动

- 列表"预警数"列 link → 跳预警列表 `warning-list.html?bizline=xxx`
- 详情页"合作期间主体风险监控情况"表数据 → 来自预警表的分类统计

### 14.4 与付款管理联动

- 报告生成触发条件 = 付款记录的"已付款"状态
