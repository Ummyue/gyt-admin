## 1. 业务定位

**库点信息管理**是仓储管理的**物理仓库位置管理页**——业务人员配置仓库地址、库点类型、联系人、监控设备等基础信息。

| 维度 | 库点信息管理（本页）| 仓房管理（warehouse-warehouse）|
|------|---------------------|-------------------------------|
| 数据范围 | 库点（物理位置）| 仓房（库点内的仓房）+ 货位 |
| 颗粒度 | 1 个库点 = N 个仓房 | 1 个仓房 = N 个货位 |

### 1.2 v1.7.99.119 关键改动

- 从 v1.0 单字段重构为 **v1.7.99.119 库点 + 仓房 + 货位 三级结构**：
  - 库点：物理仓库地址
  - 仓房：库点内的仓房
  - 货位：仓房内的具体货位

## 2. 字段规则

### 2.1 库点信息字段

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 库点编号 | auto | - | 系统生成 |
| 库点名称 | input | 是 | 必填 |
| 库点地址 | input | 是 | 必填 |
| 库点类型 | select | 是 | 自营仓/第三方仓/监管仓 |
| 联系人 | input | 是 | 必填 |
| 联系电话 | input | 是 | 必填 |
| 监控设备数 | int | - | 灰置（关联 warehouse-video）|
| 仓房数 | int | - | 灰置 |
| 操作 | button | - | 编辑 / 查看仓房 / 删除 |

### 2.2 校验规则

| 场景 | 校验 |
|------|------|
| 删除有仓房的库点 | 红字提示"该库点有 N 个仓房，无法删除" |
| 联系电话格式 | 11 位手机号格式校验 |

---

## 3. 跨模块联动

| 联动 | 行为 |
|------|------|
| 仓房管理 | 库点 → 仓房（1:N）|
| 库点监控 | 库点 → 监控视频（1:N）|
| 巡库记录 | 巡库按库点 → 仓房 → 货位 维度登记 |
| 入库/出库 | 入库/出库单据关联到具体货位 |
