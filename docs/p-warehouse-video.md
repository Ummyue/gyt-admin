## 1. 业务定位

**视频监控-库点监控**是港通供应链的**仓储可视化监控页**——实时查看各仓库/库点的监控视频、回放历史录像、异常事件告警。

**应用场景**：
- 仓库管理员实时查看仓库作业情况
- 风控审核员远程审查出入库过程
- 客户自助查询货物存储状态
- 异常事件（货损/盗窃/火灾）追溯

**v1.7.99.152 当前状态**：原型置为**统一缺省页**——页面中明确描述"功能建设中（与线上保持一致）"，列出 5 项预期功能，原型无改动项。

## 3. 字段规则

### 3.1 预期字段（**线上系统**）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 摄像头 ID | 字符串 | 系统自动生成 |
| 所属仓库 | 字符串 | 关联仓库名称 |
| 安装位置 | 枚举 | 大门/卸货区/库内/办公区/周界 |
| 摄像头型号 | 字符串 | 海康/大华/宇视 |
| IP 地址 | IP | 192.168.x.x |
| 在线状态 | 枚举 | 在线/离线/故障 |
| 最后心跳 | 日期时间 | yyyy-MM-dd HH:mm:ss |
| 录像保留天数 | 整数 | 默认 30 天 |
| 实时画面 | 视频流 | RTSP/HLS 协议 |
| 异常事件 | 列表 | 最近 N 条告警 |

## 5. 异常处理

| 场景 | 处理 |
|------|------|
| 摄像头离线 | 红色告警 + 自动通知运维 |
| 录像丢失 | 黄色告警 + 提示"录像完整性校验失败" |
| 异常事件（货损/盗窃） | 红色告警 + 自动截图 + 推送风控审核员 |
| 网络抖动 | 自动重连 + 最多重试 3 次 |
