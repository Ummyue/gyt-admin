# 02.19 审批管理 · 流程编排画布

> **页面**：`approval-flow-editor.html`
> **版本**：v1.1.0（2026-10-15）
> **模块归属**：数字供应链 → 审批管理 → 流程编排画布
> **引擎**：`shared/js/approval-engine.js` v1.1.0
> **上游页面**：`approval-flow-list.html`（审批流程配置）

---

## 1. 业务定位

**v1.1.0 把流程编排从配置列表页中拆出，独立成画布页**。原因是节点编排本质是一张「有向流程图」，塞在列表卡片下方会导致：

| v1.0.0 的问题 | v1.1.0 的处理 |
|---|---|
| 编排区和模板列表同页，节点一多就要长距离滚动 | 独立画布页，专注单条流程，右侧常驻属性面板 |
| 编辑后要滚回列表才能看到结果 | 保存后回列表，列表「编排」按钮即入口 |
| 节点增删靠底部一排「+ 串行 / + 会签 / + 分支」按钮，插入位置不可控 | 画布上**每两个节点之间都有连接线和 `+` 按钮**，插入位置明确 |

**入口**：`approval-flow-list.html` 的「编排」按钮 / 「新建流程」按钮
**URL 约定**：`approval-flow-editor.html?flowId={flowId}`，新建用 `?flowId=new`

## 3. 节点卡片

每张卡片显示：

| 区域 | 内容 |
|---|---|
| 序号圆点 | ①②③…，颜色 = 审批人所属部门色 |
| 节点名 | 可省略号截断，hover 显示全名 |
| 操作区 | `↑` 上移 / `↓` 下移 / `×` 删除（发起与归档节点禁用） |
| 类型标签 | 发起 / 串行审批 / 并行会签 / 条件分支 / 归档 |
| 人员行 | 👤 姓名 + 脱敏手机号（会签显示全部成员） |
| 提醒行 | ⏰ 未处理满 Nh 提醒（仅开启提醒规则的节点） |

**发起 / 归档节点**不显示人员行，分别显示「发起人提交，系统自动记录」「系统自动归档」。

## 4. 节点属性（v1.1.0 字段变更）

| 节点类型 | 属性项 | 变更说明 |
|---|---|---|
| 发起节点 | 节点名称（只读） | — |
| 归档节点 | 节点名称（只读） | 类型标签显示为「归档」 |
| 串行审批 | 节点名称、**审批人员**、**提醒规则**、节点说明 | ⬅️ 「审批角色」改为「审批人员」；⬅️ 去掉「审批时限」，新增「提醒规则」 |
| 并行会签 | 节点名称、**会签人员**、**提醒规则**、节点说明 | 会签成员改为选人 |
| 条件分支 | 节点名称、**条件规则**、节点说明 | 无提醒规则（分支不是人工审批环节） |

### 4.2 提醒规则（v1.1.0 新增，替代审批时限）

```js
remind: { enabled: true, afterHours: 24 }
```

| 控件 | 说明 |
|---|---|
| 开启审批提醒（复选） | 关闭后小时数输入框禁用，卡片不再显示提醒行 |
| N 小时（数字输入，1~720） | 未处理满 N 小时后，向该节点审批人发送提醒 |

推送渠道：站内消息 + 短信。提醒触发记录见 `p-approval-monitor.md` §3.4。

### 4.3 会签人员

- 列表形式，每人一个下拉 + 删除按钮
- 同一人不能重复加入（重复时 Alert 提示并回滚）
- 至少保留 1 人
- 新增时自动选一个尚未加入的人员

### 4.4 条件规则

| 控件 | 选项 |
|---|---|
| 字段 | 单据金额 / 业务类型 / 合同类型 / 客户等级 / 风险等级 |
| 操作符 | > ≥ < ≤ = ≠ |
| 阈值 | 数字输入 |
| 命中时追加节点 | 审批环节下拉（业务审批 / 风控审批 / 财务审批 / 合规审查 / 放货审批 / 总经理审批） |

命中后自动带出该环节的**默认审批人**（`ROLES[key].defaultPerson`）。

## 5. 应用模块（v1.1.0 重构）

### 5.1 模块清单（8 项）

| key | 模块 | 子项 |
|---|---|---|
| `project` | 项目准入 | — |
| `contract` | 合同管理 | 采购合同、销售合同 |
| `goods_transfer` | 货转管理 | 上游货转、下游货转 |
| `payment` | 付款管理 | — |
| `refund` | 退款管理 | — |
| `settlement` | 结算单管理 | 上游结算单、下游结算单 |
| `bond_letter` | 追保函管理 | — |
| `release` | 放货管理 | — |

### 5.2 级联交互规则

| 操作 | 行为 |
|---|---|
| 勾选**无子项**模块 | 直接生效 |
| 勾选**带子项**模块（合同/货转/结算单） | 自动**全选**其子项，并展开子项复选区 |
| 单独取消某个子项 | 仅该子项退出，父级保持选中 |
| 最后一个子项被取消 | **父级自动取消**，避免出现「勾了父级但无子项生效」的空配置 |
| 保存时父级选中但无子项 | Alert「『xxx』已勾选，请至少选择一个应用子项」并阻止保存 |

### 5.3 存储结构

```js
applyModules: [
  { key: 'contract',       children: ['contract_purchase', 'contract_sales'] },
  { key: 'goods_transfer', children: ['transfer_up'] },
  { key: 'payment',        children: [] }
]
```

## 6. 画布操作

| 操作 | 位置 | 行为 |
|---|---|---|
| 新建流程 | 列表页标题行 | 跳 `?flowId=new`，默认 3 节点（提交 → 业务 → 归档） |
| 编排 | 列表行 | 跳 `?flowId={id}` |
| 插入节点 | 两节点之间的连接线 `+` | 在该位置插入串行节点并选中 |
| 添加节点 | 画布右上 | 在归档节点之前插入串行 / 会签 / 分支并选中 |
| ↑ ↓ | 卡片右上 | 调序；发起与归档节点不参与互换 |
| × | 卡片右上 | 删除（二次确认）；发起与归档节点禁用 |
| 点击卡片 | 画布 | 选中，右侧属性面板加载 |
| 流程图预览 | 画布右上 | 展开流程链 + 金额模拟器 |
| 保存流程 | 标题行 | 校验 → 写 localStorage → 回列表页 |
| 返回列表 | 标题行 | 有未保存修改时二次确认 |

**未保存标记**：任一字段改动后标题旁出现「● 有未保存的修改」。

| 校验 | 提示 |
|---|---|

| 父模块选中但无子项 | 「『xxx』已勾选，请至少选择一个应用子项」 |

## 8. 字段规则

### 8.1 流程模板（v1.1.0）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 内置 `standard`/`simple`/`highRisk`；新建 `flow_{时间戳}` |
| `name` | text | 流程名称 |
| `desc` | text | 流程说明 |
| `status` | enum | `draft` / `enabled` / `disabled` |
| `applyModules` | array | **v1.1.0 改名**，结构见 §5.3 |
| `nodes` | array | 节点数组，见 §8.2 |
| `updatedAt` / `updatedBy` | datetime / string | 自动记录 |

**持久化**：`localStorage['ygt_approval_flow_templates_v2']`
> v1.0.0 用的是 `_v1`，数据结构不兼容（节点字段、模块结构全变），**不做迁移**，直接读内置模板。

### 8.2 节点

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 节点唯一标识 |
| `type` | enum | `start` / `serial` / `parallel_all` / `branch` |
| `name` | text | 节点显示名 |
| `roleKey` | enum | 审批环节 key（用于分支指向与默认配色） |
| `approver` | string | **v1.1.0 新增** 审批人员 id（`type=serial` 且非归档时必填） |
| `approvers` | string[] | **v1.1.0 新增** 会签人员 id 数组（`type=parallel_all` 时必填） |
| `remind` | object | **v1.1.0 新增** `{ enabled, afterHours }` |
| `condition` | array | 仅 `branch`：条件规则 |
| `auto` | boolean | 归档节点标记（不可删除） |
| `desc` | text | 节点说明 |
| ~~`slaHours`~~ | — | **v1.1.0 下线**，由 `remind` 替代 |
