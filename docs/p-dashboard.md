## 1. 业务定位

**驾驶舱**是数据中心的首页（高管视角）——按"统计周期 + 业务类型"维度展示项目总数/执行中项目等关键指标 + 概览/项目/合同/客户 4 个状态 tab。

**v1.7.99.200 决策**：当前 prototype 是 v1.7.99.7 占位版（"驾驶舱（晋晋）"），待业务确认后重制。本 docs 记录当前占位版本字段。

## 2. 页面结构

### 2.1 顶部筛选区（2 字段）

| # | 字段 | 类型 | 选项 |

| 1 | 统计周期 | date-range | 开始时间 ~ 结束时间 |

| # | tab 名 | count | 说明 |

| 3 | 合同 | 236 | 合同维度数据 |
| 4 | 客户 | 182 | 客户维度数据 |

## 3. 字段定义

### 3.1 筛选字段

| 字段 | 类型 | 选项 | 默认 |
|------|------|------|------|
| 统计周期 | date-range | - | 空 |
| 业务类型 | select | 请选择/全部/存货业务/预付业务/账期业务/购销业务 | 请选择 |

### 3.2 状态 tab 字段

| 字段 | 数据来源 | 说明 |
|------|----------|------|
| 概览 | 全模块汇总 | 项目总数 + 合同金额 + 累计回款等 |
| 项目 | 项目准入（02.03）| 项目总数 118 |
| 合同 | 合同管理（02.05）| 合同总数 236 |
| 客户 | 客户准入（02.02）| 客户总数 182 |

### 3.3 卡片字段

| 字段 | 数据来源 | 规则 |
|------|----------|------|
| 编号 | 系统 | DASHBOARD + YYYYMM |
| 状态 tag | 系统 | 概览 |
| 统计周期 | 筛选条件 | YYYY-MM |
| 数据来源 | 系统 | 全模块 |
| 项目总数 | 项目准入 | 该周期内项目总数 |
| 执行中项目 | 项目准入 | 该周期内执行中项目数 |
| 合同金额 | 合同管理 | 该周期内合同金额 |
| 累计回款 | 回款管理 | 该周期内累计回款 |

## 4. 按钮交互

| 按钮 | 行为 |
|------|------|
| 状态 tab | 切换卡片数据 |
| 操作"查看" | 跳对应模块详情（项目/合同/客户/概览）|

---

## 5. 数据规则

- **概览 tab** = 全模块汇总数据
- **项目/合同/客户 tab** = 单维度汇总数据
- count 数字 = 系统当前真实数据条数（mock）

---

## 6. 异常处理

| 场景 | 提示 |
|------|------|
| 统计周期为空 | 显示全部数据 |
| 数据加载失败 | "数据加载失败，请重试" |

---

## 7. 跨模块流转

- **上游数据**：项目准入（02.03）/ 合同管理（02.05）/ 客户准入（02.02）/ 回款管理（02.14）→ 驾驶舱
- **下游消费**：驾驶舱 → 项目台账表 / 业务线台账表 / 资金占压表 / 库存明细表 / 应收应付表
