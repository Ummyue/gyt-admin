## 1. 业务定位

**客户信息详情**是客户管理（02.02）的**查看/编辑客户资料页**——业务人员查看客户的完整信息（基本信息 + 额度信息 + 业务记录 + 风险记录等），并支持修改（v1.7.99.130 后）。

### 1.1 入口

| 入口 | URL | 说明 |
|------|------|------|
| 客户列表行点击 | `./customer-detail.html?customerId={客户ID}` | 主入口 |

### 1.2 v1.7.99.130 关键改动

- 从 v1.0 单区块重构为 **v1.7.99.130 多 tab 结构**：
  - Tab 1：基本信息（默认）
  - Tab 2：额度信息
  - Tab 3：业务记录（关联合同/结算/回款）
  - Tab 4：风险记录（关联预警/黑名单）

## 2. 字段规则

### 2.1 顶部 metadata

| 字段 | 来源 |
|------|------|
| 客户编号 | URL 参数 |
| 客户名称 | display |
| 客户类型 | tag（核心企业 / 上游供应商 / 下游客户）|
| 客户状态 | tag（正常 / 黑名单 / 注销）|

### 2.2 Tab 1：基本信息

| 字段 | 类型 | 必填 |
|------|------|------|
| 客户名称 | input | 是 |
| 统一社会信用代码 | input | 是 |
| 法定代表人 | input | 是 |
| 注册地址 | input | 是 |
| 注册资本 | number | 是 |
| 经营范围 | textarea | 是 |
| 联系人 | input | 是 |
| 联系电话 | input | 是 |
| 邮箱 | input | 否 |
| 备注 | textarea | 否 |

### 2.3 Tab 2：额度信息

| 字段 | 计算 |
|------|------|
| 授信总额度 | 灰置（来自额度管理）|
| 已用额度 | SUM(敞口金额) |
| 剩余额度 | 授信总额度 - 已用额度 |
| 保证金账户余额 | SUM(保证金池 paid) |
| 风险敞口 | SUM(敞口金额) |

### 2.4 Tab 3：业务记录

| 字段 | 关联 |
|------|------|
| 关联合同数 | COUNT(合同 WHERE customerId) |
| 关联结算单 | COUNT(结算单) |
| 关联回款 | COUNT(回款) |
| 业务线数 | COUNT(业务线) |

### 2.5 Tab 4：风险记录

| 字段 | 关联 |
|------|------|
| 预警记录数 | COUNT(预警) |
| 黑名单状态 | display |
| 历史违约次数 | COUNT(违约) |

## 3. 按钮交互

### 3.1 顶部按钮

| 按钮 | 行为 |
|------|------|
| 修改 | 进入编辑模式（仅 Tab 1 可编辑）|
| 加入黑名单 | 二次确认 → 状态=黑名单 |
| 调整额度 | 跳 `customer-quota.html?customerId={ID}` |
| 返回列表 | 跳 `customer-list.html` |

### 3.2 Tab 切换

```javascript
function switchTab(el, key) {
  document.querySelectorAll('.detail-tab').forEach(t => t.classList.remove('active'));
  el.classList.add('active');
  document.querySelectorAll('.tab-content').forEach(panel => { panel.style.display = 'none'; });
  document.getElementById('tab-' + key).style.display = '';
}
```

## 4. 异常处理

| 场景 | 处理 |
|------|------|
| URL 参数 `customerId` 缺失 | 顶部红色 bar + 返回列表 |
| 客户已注销 | 顶部橙色 bar 提示"该客户已注销，仅可查看历史" |
| 客户加入黑名单 | 黑名单 tag + Tab 4 红字提示 |
| 编辑模式下必填字段为空 | 红字提示 |
